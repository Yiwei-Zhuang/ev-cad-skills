# 块字典（Block Dictionary）

DXF 中与管网流向相关的块（INSERT）语义速查。「领域角色」= 块在排水领域中的含义；「现行实现」= 本 skill 各步骤的实际处理（规范见 [implementation-spec.md](implementation-spec.md)「出水口识别」）。

| 块名 | 含义 | 所在图层 | 领域角色 | 现行实现 |
|---|---|---|---|---|
| `LX` | 流向箭头 | 管线图层或注记图层（见 `YSLINE`、`YS_ZJ` 两种） | 标注于 line 之上，表示该线段的流向 | **唯一定向来源**：全局搜（不限层，`--arrow-layer` 可选过滤），块名可 `--arrow-block` 覆盖；匹配到管段后该边 `direction_source = "arrow"`（可信，白） |
| `CSK` | 出水口 | `YSPOINT` | 汇水网络的终点 | **唯一出水口标记**：绑定容差内聚类节点置 `type = "CSK"`；汇点为 CSK 时 `outlet` 非空、画终点箭头；块名可 `--outlet-block` 覆盖 |
| `YJ` | 雨井 | — | 汇水起点（雨水由此入网） | **不识别、不绑定、不记录**：起点由「先主干后分支」的拓扑判定决定，不由井块类型决定 |
| `YB` / `YLK` 等 | 普通井 | — | 中间节点 | 同上，不参与任何方向、主干、支管判定 |

## 备注

- `YJ` 的领域角色是汇水起点，现行规范**刻意忽略**之——若把每个雨井都当起点，起点标记会淹没图面（见规范「核心思想：拓扑端点 ≠ 语义起点」）。
- 箭头跨层混搜的安全性由几何匹配兜底：箭头须距管段 ≤ `arrow-tol`（默认 1 cm）且取最平行候选，远离管线的图例箭头自然落空；`--arrow-layer` 留作病态图纸（异系统同名块压线）的手动过滤阀。
- `lv_yuan_lu_test.dxf` 的 `YSPOINT` 层出现乱码井块 `___0` / `___1` / `___3`，按普通井忽略，不参与判定。
- 若未来要按井类型增强起点/终点判定（如 YJ 计入候选分支源头），修改 `extract.py` 的块识别逻辑，并同步更新本表与规范「出水口识别」一节。
- 新图出现未登记的块时，先在此补一行再决定是否参与判定，避免散落的口头知识。
