# 实现规约（normative）— 管线流量估算唯一规范

本文件是四步规则的唯一规范来源，将概念规则操作化为可复现的判定与几何程序。脚本（`scripts/`）是本规范的实现，已在 `src_dxf/rain_only_test.dxf` 上通过逐字段对照验收（9 树 / branch_min 25.0 / CROSSLEN 42.93，重跑字节级一致）。

## 步骤 1 — 提取（extract.py）

读取用户指定的 DXF 图，找出用户指定的管线图层（如 `YSLINE`）中的管段（LINE / 多段线），并提取两类辅助元素——`LX` 箭头块（确定流向）、`CSK` 出水口块（确定出水口）——将三者转化为 JSON：管段端点聚类为 `nodes`（single-linkage，`snap_tolerance`；簇均值定坐标，按 (x,y) 排序定 ID），管段连同方向写入 `edges`。JSON 六层契约见 [json-schema.md](json-schema.md)。

### 方向判定

方向依据只看两个来源，按此优先级：

1. **有 LX 箭头** → 箭头方向即下游方向，`direction_source = "arrow"`（可信，白）。箭头匹配容差 `arrow_match_tolerance`（0.01）；多候选取最平行者，平行并列取近者，再取边 ID。
2. **无箭头** → 猜一个方向并明确记录为猜测，`direction_source = "guessed"`（存疑，粉红）。猜测所用启发式属于实现细节，此处不规定；但所用规则名必须写入 `meta.guess_rule`（当前实现 `bfs-to-csk` = 向 CSK 出水口做多源 BFS、按距离梯度定向，无 CSK 分量向最小 (y,x) 节点定向），否则 A.5 的确定性承诺对 guessed 边不成立。

定向完成后，每条边 `direction = "downstream"`。随后检测**同一对无序节点之间的重复边**：若出现两条及以上，保留一条作下游主边（优先 `arrow` 来源、其次较长者），其余边若方向相反记 `reverse_edge`（`direction = "upstream"`）、若同向记 `duplicate_edge`，均写入 `anomalies` 并在绘制时用粉红。被标记的多余边与 `cross_tree_edge` **不参与后续拓扑分析**（主干提取、分支判定、拆树归属），仅按步骤 4 悬浮绘制。

- **CSK 不参与方向判定**。CSK 节点的唯一作用是：标记出水口节点（`type = "CSK"`），供步骤 3 判定 `outlet`、步骤 4 决定「是否画终点箭头」。
- 只要方向是「猜的」，绘制时必须用粉红色与白色可信 flow 区分开。

### 出水口识别

- 只识别 `YSPOINT` 图层中的 **CSK** 块（出水口）：把 CSK 绑定到 `outlet_bind_tolerance`（1.0）内的聚类节点，绑定到的节点 `type = "CSK"`；其余节点一律 `type = "junction"`。
- 普通井（YB/YJ/YLK 等）不识别、不绑定、不记录——它们不参与任何方向、主干、支管判定。

## 步骤 2 — 拼接（join.py）

根据步骤 1 输出的 JSON，在**有效边**（剔除异常边）上求**无向连通分量**。每个分量在 `components` 中占一条：此时只填 `id`、`node_ids`/`edge_ids`、`node_count`、`edge_count`；`outlet/source/sink/sources/chains/main_path/branch_count/is_valid` 留待步骤 3 补全。

## 步骤 3 — 确定主路径（trunk.py）

在步骤 2 输出的 `components` 基础上，为每个连通分量确定唯一**汇点（sink）**与**源点（source）**，并提取**主干路径（trunk path）**。

### 前提与定义

- **有向化**：每个连通分量必须是**有向图**。以步骤 1 已定向的 `edges`（`from`→`to` 沿流向）为边，节点的**入度**为流入管段数、**出度**为流出管段数。
- **汇点（sink）**：出度为 0 的节点。领域不变量是**一个排水树有且仅有一个汇点（一个出口）**；若某分量出现 0 个或多个汇点，说明数据有误（多棵树被错误连在一起 / 成环），记为异常。
- **死端 ≠ 出口**：出度为 0 的节点里只有 **CSK 才是真正的出口**。非 CSK 死端是「断头管道」，分两种：短断头（< `branch_min_length`，从汇流点叉出的断枝，应剔除不作图）、长断头（≥ `branch_min_length`，真正的独立断头管道，才作为合法 sink，`outlet = null`）。
- **出水口（outlet）**：汇点若恰为 **CSK** 节点，则该分量有明确出水口，`outlet` 记录其节点 ID；否则 `outlet = null`（仍属合法拓扑）。**「无 CSK」≠「非法」**：合法性只看汇点是否唯一（`|sinks| == 1`），与汇点是否为 CSK 无关。
- **起点（source）**：单数，指主干路径最上游端，步骤 3 第 5 步回设：先剪除主干**头部短桩**，再锚定到第一个显著顶点，写入 `components[].source`。起点 ∈ 源头列表，但**不必然等于拓扑源**。
- **头部短桩（leading stub）**：主干开头累计长度低于显著性阈值 T（见附录 A.3）的连续短边；视同就地接入，不入图、不留在 `main_path` 中。拓扑源可能只是头部短桩的远端——那是数据接痕或雨水口短接头，不是水流真正开始的位置。
- **源头列表（sources）**：复数，指保留边子图上所有入度为 0 的节点（含主干起点与保留分支的最上游叶子），写入 `components[].sources`；`chains[].source` 则引用其中某一个，作为某条链的起点。三者关系：`source ∈ sources`，`chains[].source ∈ sources`。
- **路径权重（weight）**：**主干 = 最长路径**。边的权重取该边自身上游**累计长度**（沿有向边向下游逐级累加 `edges[].length`）。

### 处理步骤

1. **寻汇**：扫描每个分量内节点的入/出度，得到汇点集 `sinks`；入度为 0 的节点暂不当起点（见「核心思想」）。
2. **剪短断头**：对每个非 CSK 死端，对其**每条入边链**分别沿上游回溯：只在纯穿越节点（入度 = 1 且出度 = 1）继续上溯，遇汇流（入度 ≥ 2）、分叉（出度 ≥ 2）或源头（入度 0）即停——死端节点自身是汇流点时，各入边链独立判定，**所有链累计长度均 < `branch_min_length` 才整簇剔除**，任一链达标即为合法长断头，留待分支判定。剔除后该死端不再作为 sink。**必须在拆树之前做**——否则短断头被拆成独立树后，其 source 会被误当成新起点、死端被误当成新出口。此阶段**仅用绝对下限**（主干尚未提取，比例条件无从谈起），见附录 A.1.4。
3. **合法性校验与拆树**：剪短断头后，剩余 sink（CSK 出口 + 长断头）才参与校验。`|sinks| == 1` 为合法。若 `|sinks| > 1`（多出口，数据错误），记 `multi_sink` 异常后，按汇点拆成多棵**单出口树**——边按**流向归属**：每条边属于其下游端沿流向实际到达的汇点（叉口裁决与细则见附录 A.2），到达不了任何汇点（有向环）的边记为 `cross_tree_edge` 异常。拆完后每棵子树重新满足「单一汇点」，`is_valid = true`；若拆树后某棵子树仍无单一汇点（如孤立环），`is_valid = false`。
4. **反向提取主干路径**：从唯一汇点出发，沿有向边**逆向回溯**（沿 `to`→`from`）。在每个汇流节点（入度 > 1 的节点），选择**累计长度最大**的入边继续回溯，其余入边记为支管（branch）终止。回溯直至到达入度为 0 的节点为止，得到一条**从起点到汇点的主干路径**。回溯**禁止重复访问已访问节点**（简单路径，用以破开环）。
5. **剪头部短桩并回设起点**：主干开头累计长度 < T 的连续短边（头部短桩）从主干与保留边集中剔除，首个显著顶点设为该分量的**起点**（`source`），`main_path` / `chains` 随之更新；汇点保持为 `sink`，**不因末段短而重锚**——CSK 出水口是唯一语义终点，末端方向问题由终点箭头的切线基准解决（见步骤 4）。阈值 T 与起点切线共用同一常量（见附录 A.3）。

### 核心思想：拓扑端点 ≠ 语义起点

> 这是步骤 3 最常被做错的地方。**入度为 0 的节点会被遍历一律当成 source，但其中绝大多数是就地接入主干的短小连接**，它们并不改变整体流向趋势。若把它们全部当成起点，起点标记会暴涨到接近叶子节点总数（几百个，而真正常见的只有几十个），图面被横线和噪声淹没。

因此「寻源」不是简单地收集入度为 0 的节点，而必须分层：

1. **先主干、后分支**：先按「反向提取主干路径」（最长累计长度回溯）提取主干，只有主干最上游端是**必然起点**；其余叶子一律降级为「候选分支」，不再自动成为起点。
2. **分支要「够长、够级别」才算起点**：对每个候选分支，计算其**累计长度**（从分支最远的叶子，沿分支走到「汇入主干的第一个节点」为止；分支内部的二级 tap 量到其本地汇流点，判定对象分级见附录 A.1.1）。保留分支须**同时满足双条件**（阈值取两者之较大者）：
   - **绝对下限**：累计长度 ≥ `branch_min_length`（剔除跨尺度普遍存在的就地接入/次要小支）；
   - **干支数量级比**：累计长度 ≥ 主干累计长度 × `branch_trunk_ratio`（大树缩放器：主干越长阈值越高，把大网络的保留线压到「与主干同主导级别」的大支管，默认 0.05 即 1/20）。

   任一条件不满足的，是就地接入或次要汇水、不影响 flow 总体趋势的局部连接——整条剔除，**不做任何作图**（不画 flow 线、不打起点横线、不标箭头），其连接段由主干趋势线自然覆盖。断头支（出度 0 的叶子）与源头支（入度 0 的叶子）对称，同样按双条件剔除。
3. **阈值参数化、可复现**：`branch_min_length` 是命名常量，写入 `meta`。取值方法见附录 A.3（两遍标定法），不拍脑袋硬编码。`branch_trunk_ratio` 同为命名常量写入 `meta`，默认 0.05：其职责不是区分大小支管（那是绝对下限的事），而是让阈值随主干长度同向缩放，避免大树上「绝对值达标但相对主干可忽略」的中型支管淹没图面。
4. **按保留边裁剪**：剔除支杆时，只按「保留边」的度数判定分叉点；被剔除的短支杆绝不能把主干切成一段段。分支内部汇流点上的**主链延续（上游累计最大的入边）永不作为侧支被裁**（附录 A.1.2）。
5. **迭代剔除 + 保护主干**：短支可能**嵌套**（短支上再接短支），只剔一层不够——须在「保留边」子图上**按快照轮次**（附录 A.1.3：每轮判定基于轮首图、轮末原子应用，杜绝同轮顺序依赖）反复剔除「叶子源 + 未达保留双条件」的边直至收敛；同时主干边必须**显式保护**，绝不能因是短段而被误删（主干上同样存在短段）——唯一例外是头部短桩（处理步骤 5），它在保护伞之外。

典型自检信号：若最终起点数量接近叶子总数（几百），就是漏做了「先主干后分支」，把每个端点都当成了 source。

### 异常与错误边的标记

以下情况记录进顶层 `anomalies`，且对应边/节点在绘制时用**粉红**：

- **`reverse_edge` / `duplicate_edge`**：同一对无序节点间出现多余边（环 / 双重箭头），见「方向判定」。
- **`cross_tree_edge`**：多汇点拆树时，到达不了任何汇点（有向环）的边。
- **`multi_sink`**：拆树前一个分量有多个汇点的原始事实。

## 步骤 4 — 绘制 DXF 流向图（draw.py / preview.py）

基于用户指定的源 DXF，**复制一份**作为输出底图，并依据前序步骤的 JSON 内容，将全部连通分量绘制为**管线流向图（flow map）**，供人工直观审阅。

### 图层与几何约定

- **图层（layer）**：新建独立图层，默认命名为 `<用户指定图层>flow`（如 `YSLINEflow`），不与源图层混绘。
- **实体类型**：流向统一用 `LWPOLYLINE`（多段线）绘制，保证折线连续、节点衔接平滑；编号注记为唯一例外，用单行文本 `TEXT`。
- **符号标注**：
  - **终点箭头**：仅当该分量的汇点是 `CSK` 节点（即 `outlet` 非 null）时绘制；非 CSK 汇点（断头管道末端）**不画箭头**，如实画到断点为止。箭头方向基准 = **末端切线**：与起点切线同规则、方向相反——沿主干自汇点逆行累计 T 米取弦，箭头尖点指向下游、两翼沿末端切线反向张开半角 30°；末端短边（如出水口前 5 m 短段）不使箭头歪斜。
  - **起点标记（起始横断线 / start crossline）**：在主干起点处绘制与流向**正交**的横线，标识主干起点。几何规则：
    - **方向基准 = 起点切线**：切线取沿主干自起点累计 T 米的**弦方向**。首段为长边时与首段流向一致；首段为短桩（如紧接 90° 转弯的连接短边）时取实际流出趋势，避免横线与主干平行。端线方向垂直于起点切线。
    - **中点重合**：端线的几何中点与主干起点顶点**精确重合**（共点约束），端线以起点为对称中心。
    - **对称等臂**：端线自中点向两侧**对称延伸**，两侧臂长相等（各 ½ 端线长）。
    - **首尾贯通**：端线横穿 flow 中心线，在起点处**贯穿而非仅外切**。
    - 归纳：**起点端线 = 以主干起点为中点、垂直于起点切线的对称等臂横断线**。
  - **编号注记（flow ID label）**：作图收尾步骤——为每个独立 flow（单出口树）分配十进制序号 **1..N**（按 `components[].id` 升序），并**同号双标**：起点注记与终点注记文本相同（如某 flow 编号为 1，则其起点标 `1`、终点亦标 `1`），使读者在整图任意位置都能沿号追踪同一 flow 的始末。注记用 DXF 单行文本（`TEXT`），**白色（ACI 7）**——编号标识的是 flow 整体而非某条边，不参与白/粉红的可信度区分。几何规则：
    - **起点注记插入点** = 起点沿起点切线**反向**（逆流向、指向 flow 外侧）平移 ½ 横线总长；
    - **终点注记插入点** = 汇点沿末端切线**正向**（越过终点箭头尖再向外）平移 ½ 横线总长；
    - **对齐与字向**：middle-center 对齐，旋转角 0（字头朝北）；
    - **字高** = ½ 横线总长。
  - **首尾衔接**：起点端线与终点箭头须**与流向 PLINE 的首末顶点相连**，保证起点、流向、终点构成一条连续、闭合的几何链。
- **线型与样式**：
  - **白色**：可信流向（`direction_source = "arrow"` 的边）；
  - **粉红色**：存疑/异常元素——`direction_source = "guessed"` 的边，以及顶层 `anomalies` 中标记的错误边（reverse/duplicate/cross_tree）——整条边改用粉红。异常边**不参与树的连通分量**：按自身几何偏移后独立绘制为**悬浮粉红线**，供对照 `anomalies` 人工核查；
  - 线宽统一，使用 DXF 允许的最大 `lineweight`（211），流向 PLINE、起点横断线、终点箭头统一设置（白/粉红同宽）。

### 几何生成规则

- **单一连通分量**：一个 flow（一棵排水树）的**所有 PLINE 必须首尾相连、构成一个连通分量**——主干 + 分支合在一起只能是一个整体，不允许互相脱离。这是步骤 4 最常被做错的地方。
  - **节点统一偏移坐标**：等距偏移是**逐节点**的，不是逐管段的——不要对每条管段各自独立做偏移（那样分支会与主干在汇流点错开、断开）。**每个节点只计算一次偏移坐标**（存于顶层 `node_offset`），主干与所有分支共享这套顶点坐标，汇流点成为精确共享顶点，分支自然插到主干上。
  - **分支走到已绘制处即止**：每条分支 PLINE 从叶子出发，沿下游走到「主干节点 / 汇流节点 / 已绘制过的边」为止，共同的下游段**只画一次**（由主干或先到者覆盖）。「已绘制」的判定范围是**本树内**已绘制几何——多汇拆树共享节点时，各树按 A.4.3 各用局部偏移、各走各的完整路径，不因他树画过而提前停止（否则后画的树被截断，末端接不上本树几何）。
  - **汇流顶点不可合并**：汇流点是**网络特征点**，做「简化拉直」时**必须保留为顶点**，不能被合并掉，否则分支失去共享点、flow 被切断。
  - 典型自检信号：若一个 flow 在 DXF 里拆成了多个互不相连的 PLINE 群，就是漏做了「节点统一偏移坐标」。
- **近似平行（等距性）**：flow 是源管线折线的**法向偏移线**：偏移量全图统一，各顶点至对应源管段轴线的法向距离处处等于该偏移量。绘制与简化均不得破坏**等距性**——某段明显偏离等距关系，即说明该处被拉直或走歪。
- **避让**：避让由统一偏移量天然实现——flow 与所对应的源管段之间保持恒定法向净距即可；与**无关联**的源管线发生交叉无法避免、也不作要求。
- **简化拉直（一笔画）**：从起点出发，沿有向边逐节点向下游遍历、一笔画成折线。简化的本质是**线综合中的去冗余，而非改形**——只允许省略**共线（近共线）的加密过渡点**，凡构成折线形状的特征点一律保留为顶点：
  - **拐点（方向转折点）**：决定折线走向的形状特征点，逐个保留；省略任何一个拐点都是**以弦代折**、改变折线走向（把「直段＋斜向连接段」画成一条斜线即属此类错误）；
  - **汇流点（网络特征点）**：保留边入度 > 1 的节点必须保留，否则分支失去共享点、flow 被切断；
  - **分叉点（网络特征点）**：保留边出度 ≥ 2 的节点必须保留，否则侧支的偏移锚点不再落在父线上、flow 被切断——即使该处主干近共线也不可合并；
  - **链的起终点、汇入点、颜色切换点**天然是顶点，不在省略之列；
  - **可省略顶点 = 纯穿越点**：度数判定一律用**保留边子图**（入度 = 1 且出度 = 1），且需近共线（相邻边夹角 < 近共线容差）、相邻段同色；分叉点、汇流点即使近共线也不可省略。
  - 验收性质：简化后的 flow 折线与源折线保持**逐段平行、逐点等距**——等距性不因简化而破坏。
  - 典型自检信号：flow 出现**跨越源图拐点的长直弦**（弦与源折线明显不等距），就是拐点被误省略、发生了**过度简化**。

### 预览图输出（PNG preview，preview.py）

作图收尾步骤——除输出 DXF 外，**必须同时产出一张栅格预览图（PNG）**，与输出 DXF 同名（仅扩展名不同），供无 CAD 环境下的快速人工审阅。规格：

- **内容**：输出 DXF modelspace 全览——源管线以**灰阶细线弱化**为底图，flow 图层按图层约定着色（白 / 粉红，含横线、箭头、编号注记），无裁切、覆盖全图范围；
- **底色与尺寸**：深色底（保证白 / 粉红可辨），长边固定像素数（默认 2000 px）；
- **确定性**：渲染范围、配色、尺寸均为常量，同一输入产出可复现的图；
- **实现自由**：渲染工具不限，只约束上述产物契约。

## 附录 A — 实现规约（normative）

> 与正文表述冲突处，以本附录为准。

### A.1 分支裁剪程序

**A.1.1 判定对象分级**
- **一级分支**：入边直接指向**主干节点**的子树。累计长度 = 子树内最远叶子 → 该主干节点（不是逐段、也不是量到本地汇流点）。
- **二级 tap**：一级分支内部汇流点（保留边入度 ≥ 2 的非主干节点）上的侧支。累计长度 = 最远叶子 → 该汇流点。
- 同一子树不得在不同挂点重复判；**禁止对分支中段边单独评判**（否则长支管会被逐段拆碎、拦腰截断）。

**A.1.2 主链延续豁免**
分支内每个汇流点上，**上游累计长度最大的入边视为主链延续**，永不作为 tap 被裁；仅其余入边参与二级判定。
（防：主链上方延续段被局部累计值误杀、支链拦腰截断。）

**A.1.3 快照轮次**
每轮判定统一基于**轮首保留边子图**计算，全部剔除决定在轮末**原子应用**；轮内任何剔除不得影响本轮其他判定。反复执行直至本轮零剔除（嵌套短支在后续轮次中被继续剔除）。
（防：同轮顺序依赖导致虚假级联与不收敛。）

**A.1.4 断头支判据裁决**
处理步骤 2 的「剪短断头」（拆树前）**仅用绝对下限** `branch_min_length`——此时主干未提取，比例条件无从谈起；核心思想 #2 的「断头支对称双条件」适用于**主干提取之后**的死端叶。

**A.1.5 长断头整树裁决**
拆树后某棵子树全部边均为非 CSK 断头、且主干总长 < `branch_min_length` → 整棵树不作图（短断头组件在剪短断头阶段已被整段剔除，本条兜底拆树残余）。

### A.2 多汇拆树归属

按**流向归属**（不按最近汇点）：每条边属于其下游端沿流向实际到达的汇点。叉口（出度 ≥ 2）取**下游累计长度最大**的出边为延续方向，保证归属确定且全图一致。到达不了任何汇点（有向环）的边记 `cross_tree_edge`。
（防：按几何距离切分会把同一流向路径劈成两半，产生孤岛边与断流树。）

### A.4 节点偏移与衔接几何

**A.4.1 节点偏移归属（每节点恰计算一次）**
- 叶（入度 0）：`p + L(唯一出边) · D`；
- 汇流（入度 ≥ 2、出度 1）：入边取**上游累计长度最大**者，与出边做 miter 交点；
- 叉口（入度 1、出度 ≥ 2）：出边取**下游累计长度最大**者，与入边做 miter 交点；
- 穿越（入 = 出 = 1）：相邻两边 miter 交点；
- miter 退化（偏移线平行，如折返）：取入边法向平移点 `p + L(入边) · D`。

**A.4.2 分支端点衔接（「走到已绘制处即止」的操作化）**
分支末顶点 = 分支自身偏移线与**本树内已绘制父段折线段**的交点，按 A.3 接受域判定：分支侧 s 域与父段侧 t 域**双双在域内才有效，不做延长线求交**；无有效交点时钉回共享节点偏移顶点；多个有效交点取离共享顶点最近者。绘制按**依赖序**执行：先主干（沿主干顺序）、后其余（拓扑下游优先），保证父段几何先于子分支存在。「已绘制」仅指本树——拆树共享节点上，各树按 A.4.3 互不污染。

**A.4.3 拆树共享节点**
被拆树共享的叉点节点：绘制使用**各树局部**偏移（互不污染，先到者写入 `node_offset` 表并保留）。

### A.5 复现性与验收

- **确定性**：全部排序与并列裁决以 `(数值, 边/节点 ID)` 字典序进行，无随机性、无未定义行为；guessed 边的启发式规则名记录于 `meta.guess_rule`；同一输入重跑输出字节级一致；
- **底图版本升格**：源 DXF 低于 R2000（如 R12）时，`draw.py` 以 Importer 将底图升格为 R2000 再绘制（LWPOLYLINE 所需），升格事实与告警数记录于 `meta.base_dxf_upgraded_from` 并打印；不支持导入的实体被丢弃，仅影响底图观感、不影响 flow 几何；
- **验收项**（`validate.py`，期望值由 JSON 推导，不硬编码）：
  - **连通判定**：两实体共享顶点，**或**一方顶点落在另一方线段上（带公差），均视为连通——起点横线以中点贯穿 flow 首顶点、分支衔接点落在父段内部，都是合法连接方式。按此判定：几何连通分量数 = **树数 + 悬浮异常边群数**（reverse/duplicate/cross_tree 悬浮粉红线各计一群）；
  - 起点横断线数 = 树数、终点箭头数 = CSK 出口数；
  - 编号注记数 = **2 × 树数**（每 flow 起点、终点各一），编号 1..N 连续、无重复、**同号成对**；
  - 预览图 PNG 与输出 DXF **同名同目录**产出；
  - **法距测度**：顶点至**其所属保留边**对应源管段的最小法距，中位数 = D（容差 ±2 cm）；miter 钳制点与分支衔接点按设计偏离 D，豁免判失败、仅报告（权威值由 `draw.py` 输出；`validate.py` 另报最近边代理测度供速览）；
  - 起点总数 ≪ 叶子总数（见核心思想自检信号）。
